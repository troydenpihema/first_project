# Open World RPG (Raylib + C#)

## Requirements

Install:
- .NET 8 SDK

## Setup

Open terminal inside project folder and run:

```bash
dotnet restore
dotnet run
```

## Controls

- WASD / Arrow Keys = Move
- F = Enter / Exit Vehicle
- E = Enter Building
- Q = Exit Building
- Enter = Start Game
- Esc = Quit

## Features

- Main Menu
- World Scene
- Building Interior Scene
- Drivable Vehicle
- Roads
- Trees
- Lakes
- Top-down movement
