Jungle Relic - Arcade Hub Game

A full side-scrolling adventure platformer inspired by classic PS1-era adventure platformers.

Files:
- index.html
- style.css
- game.js

How to run:
1. Unzip this folder.
2. Open index.html in a browser, or add the folder to your arcade hub.
3. Link to jungle_relic_platformer/index.html from your hub.

Controls:
- Move: A/D or Left/Right Arrow
- Jump: W, Up Arrow, or Space
- Talk/read signs: E
- Mobile controls are included.

Game features:
- 3 full levels
- Collect fruit
- Find golden keys
- Locked relic gates
- Moving platforms
- Enemies you can stomp
- Signs/NPC-style dialogue
- Hearts/lives
- Finish screen

Note:
This is an original browser game with a nostalgic adventure-platform feel. It does not use copyrighted characters, names, sprites, or assets.
