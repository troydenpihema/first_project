Skybound Isles
===============

A polished premium-style HTML5 platform adventure game for an arcade hub.

Files:
- index.html
- style.css
- game.js

How to run:
1. Unzip the folder.
2. Open index.html in a browser.
3. Or drop this whole folder into your arcade hub and link to index.html.

Controls:
- Move: A / D or Arrow Left / Arrow Right
- Jump: Space, W, or Arrow Up
- Dash: X or Shift
- Mobile buttons are included.

Game features:
- 3 stages
- Smooth camera
- Parallax background
- Collectible crystals
- Enemy stomping
- Dash movement
- Moving platforms
- Checkpoints
- Portal/beacon progression
- Particles and screen shake
