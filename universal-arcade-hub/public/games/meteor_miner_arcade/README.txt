Meteor Miner - Arcade Hub Game

How to run:
1. Open index.html in your browser.
2. Or drop this whole folder into your arcade hub games folder.

Controls:
- Arrow Left / A = move left
- Arrow Right / D = move right
- Spacebar = drill
- Mobile buttons are included for touch screens

Files:
- index.html
- style.css
- game.js

Notes:
- Best score is saved in the browser with localStorage.
- The game is built to scale inside a full screen arcade hub container or iframe.
