NEON HOVER RUN

A Three.js arcade game built for a browser arcade hub.

HOW TO RUN
1. Unzip the folder.
2. Open index.html with Live Server, Replit, Vite, or any local/static web server.
3. Because this uses Three.js ES modules from a CDN, it is best run through a server, not by double-clicking the HTML file.

CONTROLS
Move left/right: A/D or Arrow Left/Right
Boost: W, Arrow Up, or Space
Start/restart: Enter or Space
Mobile controls are included.

ARCADE HUB NOTES
- Drop this whole folder into your arcade hub.
- Link your hub game card to neon_hover_run/index.html.
- If your hub uses an iframe, the game is responsive and should fill the frame.
