# Thread Runner

Drop the CONTENTS of this folder into:

```text
public/games/thread-runner/
```

The final structure must be:

```text
public/games/thread-runner/index.html
public/games/thread-runner/game.js
public/games/thread-runner/style.css
public/games/thread-runner/thumbnail.svg
```

Do not accidentally make this:

```text
public/games/thread-runner/thread-runner/index.html
```

```json
{
  "id": "thread-runner",
  "title": "Thread Runner",
  "description": "Run, float, stitch bridges, collect spools, and dodge needles in a fabric-world arcade runner.",
  "type": "browser",

}
```
